# Project Overview

The Project Overview collects the material you want to keep visible while working in a
mindspace: plans, decisions, prompts, research notes, and important files. It keeps these
artifacts separate from the conversation history, so they remain easy to find after a long task.

Open it from **Mindspace → Project Overview** or press **Ctrl+Shift+P**.

Use **Add Note** to create a titled artifact. The type is free-form, so you can label items as
`plan`, `decision`, `prompt`, or `research`. Use **Pin File** to add a reference to a file in
the project. Select an artifact and choose **Remove** when it is no longer useful.

Pinned artifacts are stored only in the mindspace's `.humbug` metadata and persist between
sessions.
